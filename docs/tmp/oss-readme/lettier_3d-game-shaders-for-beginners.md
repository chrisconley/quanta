## Notable conventions

- Opens with a rhetorical question to hook beginners, then immediately acknowledges the reader's likely preferred stack to reduce bounce.
- License is deliberately *narrow* — source files only, not the prose — which is unusual and worth noting.
- Table of contents is the entire body; each item is its own markdown file under `sections/`.

## Takeaway pattern

A pattern for tutorial repos: the README is a landing page and ToC, and the pedagogical content lives as per-topic files. Voice matters here — the warmth is the differentiator versus a sterile book-chapter listing.
