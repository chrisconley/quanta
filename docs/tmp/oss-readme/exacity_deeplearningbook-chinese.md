# Analysis: exacity/deeplearningbook-chinese

- **Repo**: exacity/deeplearningbook-chinese (~37.2k stars)
- **Type**: Chinese translation of Goodfellow/Bengio/Courville "Deep Learning" textbook
- **Length**: ~9.8 KB (almost entirely in Chinese)

## Sections

1. H1 title
2. Opening paragraph acknowledging imperfection and asking for reader help
3. Per-chapter translator attribution (by GitHub handle)
4. "面向的读者" (For readers) — PDF download link, reading guidance
5. "出版及开源原因" (Why published & open-sourced) — four-paragraph reasoning about royalties being donated to Guizhou students, PDF vs print, etc.
6. "致谢" (Acknowledgements) — large table: chapter × lead translator × light reviewers × EN-CN cross-reviewers; plus a long list of contributor handles
7. TODO (just "typography")
8. "注意" (Notes) — issues, copyright caveats for figures/bib
9. Markdown format explanation + conversion script link
10. HTML format pointer (pdf2htmlEX)

## Tone & style

- **Register**: personal, earnest, sometimes self-deprecating ("我们水平有限" / "our level is limited"); community-building.
- **Voice**: first-person plural, translator-collective.
- **Formatting**: Setext underline headers (`--------`); tables for contributor credits.

## Notable conventions

- README doubles as a *manifesto*: multiple paragraphs explain why the PDF is open and where the royalties go (charity). Unusual and distinctive.
- Obfuscates a contact email using `base64 --decode` inline — playful anti-spam measure.
- Explicit non-commercial-use note in the Notes section.

## Takeaway pattern

The "volunteer translation" README pattern: credits are the centerpiece, followed by ethical framing (why free, what the money funds). Typical for long-running community translation projects in the Chinese tech community.
