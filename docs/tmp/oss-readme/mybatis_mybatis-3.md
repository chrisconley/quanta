## Tone & style

- **Register**: formal, enterprise-Java. Sober and institutional.
- **Voice**: third-person declarative.
- **Formatting**: Setext-style H1/H2 (`====` / `----`) rather than ATX (`#` / `##`); shows the README's age.

## Notable conventions

- Heavy use of ecosystem badges (Sonar, OpenHub, Maven Central) — signals "this is a serious, audited library."
- Test counts by platform/JDK in-README is unusual — mostly useful for maintainers and contributors validating CI behavior.
- Points at StackOverflow for Q&A rather than GitHub Discussions — old-school community surface.

## Takeaway pattern

A canonical enterprise-library README: badges dominate, prose is minimal, ecosystem links are assumed to carry the weight. The oddity is the big test-matrix table, which reads more like a CI note than onboarding content — useful but probably belongs in CONTRIBUTING.md.
