- **Repo**: shareAI-lab/learn-claude-code (~55.1k stars)
- **Type**: Tutorial / manifesto on building agent harnesses, modeled on Claude Code
- **Length**: ~24.4 KB (one of the longest in the sample; largely prose)

1. Language switcher (EN / 中文 / 日本語)
2. H1 title + the manifesto's thesis: "Agency Comes from the Model. An Agent Product = Model + Harness."
3. "Where Agency Comes From" — argumentative essay citing DQN, OpenAI Five, AlphaStar, Tencent Jueyu, LLM agents

5. "The Mind Shift: From 'Developing Agents' to Developing Harness" — two-part definition of agent work

7. "Why Claude Code — A Masterclass in Harness Engineering" — Claude Code architecture stack
8. "The Vision: Fill the Universe with Real Agents" — aspirational/rhetorical close
9. An ASCII "AGENT PATTERN" diagram
10. (Continues further with session listings s01–s12)

## Tone & style

- **Register**: *manifesto*. Confident, opinionated, sometimes polemical ("a shell script with delusions of grandeur"; "Rube Goldberg machine").
- **Voice**: essayist; first- and second-person used for persuasion.
- **Formatting**: Markdown prose with occasional fenced ASCII diagrams; bold keywords act as emphasis bars.

## Notable conventions

- README *is* the main content — not a pointer to content. Long-form essay rather than documentation.
- Leads with historical technology citations (DQN 2013 → LLM agents 2024) to position itself intellectually before introducing the code.
- Explicit disavowal of "prompt plumbing" no-code builders — picks a side of a live community debate.
- Multiple language translations offered at the top — signals target audience extends beyond English readers.

## Takeaway pattern

The "thesis-driven repo" README: the code is secondary to the argument the repo is making. Best suited to projects aiming to shift mental models (here: "stop building prompt pipelines, build harnesses instead"). Risk: a reader looking for runnable samples has to scroll a long way.
