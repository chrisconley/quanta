## Notable conventions

- Primary pitch is in Chinese; English README is a sibling file (`README_EN.md`).
- Multiple model mirror links per row: HuggingFace, ModelScope, Baidu Netdisk — covers all download channels Chinese users can actually reach.
- Opens with a redirect to the successor project — explicit "this is legacy, use V3" banner, a contrast with projects that silently archive.
- News entries are dated and link to releases/tags — doubles as a changelog.

## Takeaway pattern

The "AI model release" README: long, table-heavy, many download mirrors, per-model comparisons, and lifecycle banners for successor/deprecation. This genre's READMEs have essentially replaced model-card PDFs as the primary artifact.
