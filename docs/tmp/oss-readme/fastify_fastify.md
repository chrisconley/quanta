## Tone & style

- **Register**: institutional but developer-friendly.

## Notable conventions

- Includes a real benchmark table (with reproducibility command) — unusual willingness to publish competitive numbers.
- Explicitly lists every team member, tier by tier, with emeritus-status recognition. Governance-forward.
- EOL policy and paid-support partner are surfaced in the README — enterprise-friendly.
- Example shows CJS + ESM + async-await variants — inclusive of all Node styles.

## Takeaway pattern

The "foundation-governed OSS" pattern: benchmarks, governance, LTS policy, sponsors, and contributors dominate the latter half. Pitching to both developers (quick-start) and enterprise adopters (support/EOL/security) in one document.
